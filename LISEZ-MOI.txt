LA LUDOTHÈQUE DE LA CLASSE — mode d'emploi
==========================================

CE QUE CONTIENT CE DOSSIER
- index.html ............ la page d'accueil (les vignettes des jeux)
- manifest.webmanifest .. permet d'installer la page comme une appli
- sw.js ................. permet aux jeux de marcher sans Internet après une 1re visite
- icone-192.png / icone-512.png ... l'icône de l'appli
Il faut déposer ces 5 fichiers ET tous les fichiers .html des jeux dans le MÊME dossier en ligne.


1. METTRE EN LIGNE (une seule fois, environ 10 minutes)
   a. Créer un compte gratuit sur https://github.com
   b. Bouton « + » en haut à droite → « New repository ».
      Nom : ludotheque   —   cocher « Public »   —   « Create repository ».
   c. Cliquer « uploading an existing file », glisser les 5 fichiers de ce dossier
      + tous les fichiers .html des jeux, puis « Commit changes ».
   d. Onglet « Settings » → menu « Pages » → Source : « Deploy from a branch »,
      Branch : « main », dossier « / (root) » → « Save ».
   e. Attendre 1 à 2 minutes. L'adresse apparaît en haut de la page « Pages » :
         https://VOTREPSEUDO.github.io/ludotheque/

2. DANS LE PADLET
   Nouveau post → « Lien » → coller l'adresse ci-dessus.
   Une seule adresse pour toute la ludothèque.
   (On peut aussi coller l'adresse d'un seul jeu :
    https://VOTREPSEUDO.github.io/ludotheque/passer_par_10.html)

3. VÉRIFIER LES NOMS DE FICHIERS
   Une vignette grisée « pas encore en ligne » = le fichier n'est pas trouvé.
   Soit il n'est pas déposé, soit son nom est différent de celui écrit dans la liste.
   → Ouvrir index.html avec le Bloc-notes, chercher la liste « APPLIS » tout en haut,
     et corriger « fichier: "..." » pour qu'il soit EXACTEMENT le nom du fichier
     (majuscules, tirets bas et accents compris — le plus sûr : pas d'accent, pas d'espace).

4. AJOUTER UN JEU PLUS TARD
   - Déposer le nouveau fichier .html sur GitHub (« Add file » → « Upload files »).
   - Dans index.html, copier une ligne { titre: ... } de la liste, la modifier, redéposer index.html.
   Les adresses ne changent jamais : le Padlet reste à jour tout seul.

5. INSTALLER COMME UNE APPLI (tablette, téléphone, ordinateur)
   - Android / Chrome : ouvrir l'adresse → menu ⋮ → « Installer l'application »
     ou « Ajouter à l'écran d'accueil ».
   - iPad / iPhone (Safari) : bouton Partager → « Sur l'écran d'accueil ».
   - Ordinateur (Chrome ou Edge) : icône d'installation dans la barre d'adresse.
   Les jeux déjà ouverts une fois restent utilisables même si le réseau de l'école coupe.

6. PRÉCAUTIONS
   - Tester l'adresse depuis le réseau de l'école avant de tout basculer
     (certains filtres académiques bloquent des sites).
   - Le dépôt est public : n'y mettre aucun nom d'élève.
   - Les filtres choisis (ex. « CE1 ») sont mémorisés sur chaque appareil.
